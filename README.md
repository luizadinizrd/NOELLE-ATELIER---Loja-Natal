# NOËLLE ATELIER

Projeto acadêmico fictício de uma loja de moda natalina, desenvolvido com HTML, CSS e JavaScript.

## Integrantes

- **Luiza Diniz** — JavaScript e funcionalidades.
- **Lívia Dobelin** — HTML, CSS e identidade visual.
- **Felipe Elias** — Catálogo, conteúdo e publicação.

## Páginas

- `index.html` — Página inicial e produtos em destaque.
- `produtos.html` — Catálogo com 50 produtos, busca e filtro por categoria.
- `sobre.html` — História fictícia, missão, visão, valores e equipe.
- `galeria.html` — Moodboard visual da coleção.
- `contato.html` — Formulário com validação no navegador.

## Funcionalidades JavaScript

- Renderização dinâmica dos 50 produtos.
- Busca por nome e descrição.
- Filtro por categoria e contador de resultados.
- Exibição de produtos em destaque na página inicial.
- Carrinho demonstrativo com `localStorage`.
- Menu responsivo.
- Slideshow automático na página inicial, com controles de navegação.
- Contagem regressiva para o Natal.
- Validação do formulário de contato.
- Efeito de neve decorativo.
- Reprodução opcional de música natalina por meio de arquivo MP3, iniciada após clique do usuário.
- Botão para voltar ao topo.

## Como executar

1. Baixe ou clone o repositório.
2. Mantenha a estrutura de pastas e os arquivos do projeto.
3. Abra o arquivo `index.html` em um navegador.

## Imagens e créditos

- As imagens decorativas da galeria e do banner utilizam URLs do Unsplash.
- As imagens individuais dos produtos estão armazenadas localmente na pasta `img/produtos/`.
- Os créditos das imagens e da trilha sonora devem respeitar as respectivas fontes e licenças de uso.

## Observações

- A loja, seus contatos, produtos e preços são fictícios.
- O formulário é demonstrativo e não realiza o envio de e-mails.
- A música é reproduzida a partir do arquivo `js/All Want For Christmas.mp3`.
- O navegador exige uma interação do usuário para iniciar a reprodução do áudio.
